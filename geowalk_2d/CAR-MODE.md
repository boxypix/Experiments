# Режим машины — настройки

**Единственное место для правок: `settings.json`**

После изменений: `npm run snapshot` (для `file://`) или перезагрузка при `npm start`.

**Клавиши:** `C` — переключить вид камеры (сзади ↔ сверху).

Спрайт `car_0.png`: **2400×400**, четыре кадра по **600 px** (0–2: сзади при повороте, 3: вид сверху).

---

## Камера (вид сзади)

| Параметр | По умолч. | Эффект |
|----------|-----------|--------|
| `carCameraHeight` | `7` | Высота камеры, м |
| `carCameraPitch` | `74` | Наклон вниз, ° |
| `carLookAheadM` | `10` | Точка взгляда впереди от машины, м |

## Камера (вид сверху, клавиша C)

| Параметр | По умолч. | Эффект |
|----------|-----------|--------|
| `carTopCameraHeight` | `14` | Выше и дальше |
| `carTopCameraPitch` | `15` | Наклон MapLibre: `0` = строго сверху, `90` = горизонт |
| `carTopLookAheadM` | `0` | Центр камеры на машине |
| `carTopZoom` | `18.5` | Масштаб карты (дальность вида) |

## Спрайт

| Параметр | По умолч. | Эффект |
|----------|-----------|--------|
| `carSpriteSrc` | `"images/car_0.png"` | Файл спрайт-листа |

## Точки-коллекционки (3D-кубики, несколько типов)

Вокруг игрока появляются случайные **3D-кубики** (`fill-extrusion`, как 3D-деревья) — настоящая 3D-геометрия, корректно перекрывается домами/рельефом. Кубики крутятся вокруг вертикальной оси. При наезде (в радиусе `hitRadiusM`) кубик мгновенно исчезает и сразу появляется новый. Точки работают во всех режимах передвижения.

Поддерживается несколько **типов** кубиков — массив `carPinTypes` в `settings.json`. Каждый тип рендерится отдельным слоем.

Поля типа: `id`, `color`, `count`, `spawnMaxM` (радиус генерации, м), `hitRadiusM` (радиус сбора, м), `sizeM` (ребро, м), `baseM` (высота над землёй, м).

Типы по умолчанию:

| id | color | count | spawnMaxM | hitRadiusM | sizeM | baseM |
|----|-------|-------|-----------|-----------|-------|-------|
| `it_green` | `#C8FF00` | 5 | 800 | 20 | 3 | 2 |
| `it_orange` | `#FF6F00` | 5 | 500 | 10 | 6 | 1 |

Глобально: `carPinSpinDegPerSec` (`90`) — скорость вращения, °/с. Вращение по умолчанию выключено у каждого типа (`spinEnabled: false`), включается в debug dots.

**Stats (снизу слева):** две круговые диаграммы (60×60, толщина 8) — счётчики собранных кубиков. `diag one` — цвет `it_green`, шкала 0…240; `diag two` — цвет `it_orange`, шкала 0…50. В центре — bold-число (текущее значение).

**Debug dots (клавиша `F`):** оверлей по центру экрана (на 100px выше центра). Живые параметры каждого типа кубиков выведены **таблицей**: строки — параметры (радиус генерации, кол-во, радиус сбора, размер, высота над землёй), столбцы — типы (`it_green`, `it_orange`, …). Ниже — переключатели показа точек в каждом режиме передвижения (Режим голубя / Прогулка / Машинка — все включены по умолчанию).

Точки генерируются во всех режимах передвижения (не только в машине).

### Эффекты сбора (overlay `effects`)

Оверлей визуальных эффектов (`modules/effects-overlay.js`). Первый эффект — вспышка рамкой при сборе пина: рамка появляется и за `fxCollectBorderSec` затухает в прозрачность.

| Параметр | По умолч. | Эффект |
|----------|-----------|--------|
| `fxCollectBorderColor` | `"#22e05a"` | Цвет рамки |
| `fxCollectBorderWidthPx` | `30` | Толщина рамки, px |
| `fxCollectBorderSec` | `1` | Время затухания, с |
