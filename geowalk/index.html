Rain: gray volumetric fog. Snow: white volumetric haze. Fly-through from any direction.
3D model
Shifts the 3D mesh relative to the fixed pitch/tilt axis (car anchor). X=east, Y=north, Z=up.
RT shadows
Low-quality BasicShadowMap. Light/map snap while walking; casters rebuild rarely. Smaller map size = less GPU.
Optimization
Three origin / cache — faster over long distances. Lower 3D pixel ratio = less GPU load.
Buildings
5 tones on building-3d. Random offset shifts each footprint in GeoJSON (MapLibre translate is layer-wide only).
3D post-processing
Full viewport: MapLibre + Three.js. Motion blur uses frame accumulation.
